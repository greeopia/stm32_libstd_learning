# Python 网络时间串口脚本

Python 脚本每隔 10 秒读取一次 `https://utctime.app/api/now/Asia/Shanghai` 的 `datetime` 字段，随后通过串口发送给 STM32F103。

串口参数与 USART1 配置一致：115200 波特率、8 数据位、无校验、1 停止位、无硬件流控。

发送内容是标准 JSON。日期和时间之间的 `\n` 是 JSON 转义字符，消息末尾使用 `\r\n` 分帧：

```text
{"datetime":"2026-09-11\n13:54:01"}\r\n
```

## 安装依赖

```powershell
python -m pip install -r requirements.txt
```

## 启动

只有一个串口时会自动连接：

```powershell
python time_serial_bridge.py
```

有多个串口时，明确指定 STM32 的端口：

```powershell
python time_serial_bridge.py --port COM3
```

也可以修改获取间隔：

```powershell
python time_serial_bridge.py --port COM3 --interval 10
```

只测试网站返回和 JSON 格式，不打开串口：

```powershell
python time_serial_bridge.py --preview
```

按 `Ctrl+C` 停止脚本。串口不能同时被本脚本和串口助手占用。
