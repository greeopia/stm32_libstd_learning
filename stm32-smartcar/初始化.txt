START ──→ 从机地址+写 ──→ 寄存器号(0x3B) ──→ 重复START ──→ 从机地址+读 ──→ 14字节数据 ──→ NACK ──→ STOP
└──────────────── 地址阶段，CPU 必须一步一步走 ────────────────┘  └──── DMA 接管 ────┘

START → 设备写地址 → 寄存器地址 0x3B
      → 重复 START → 设备读地址
      → DMA 搬运 14 字节 → DMA TC 中断发出 STOP
	  


蓝牙串口: 
USART1_TX/RX: (PB6PB7) (TX: DMA1CH4)
RX:IDLE+dma(DMA1CH5) TX:dmaTC+dma
VCC(5V: L298N的5V输出) GND
PA7: 蓝牙state引脚

RX:可以接收普通转向数据，也可以接收json配置参数（要上双缓冲吗？）
TX:发送当前一些参数到vofa

dma: 外设寄存器 <-> Flash(dma寄存器)
flash->外设: 外设地址不自增，数据地址自增

虽然数据是 float，DMA 仍然每次搬一个字节，原样搬完一个浮点数的四个字节(一字=4字节)

L298N要求pwm输入引脚驱动频率为1k到5k赫兹 

在PSC=10-1,ARR=7200-1 (1kHz)下，当CCR=0.38f*ARR时才能空转
